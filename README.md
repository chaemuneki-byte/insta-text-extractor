# 인스타 텍스트 추출기

인스타그램 릴스·카드뉴스(캐러셀) 링크만 넣으면

- 🎬 영상·이미지를 내려받고
- 🗣️ 영상 속 **말(또는 노래 가사)** 을 텍스트로 뽑고
- 🔤 영상 **화면에 박힌 자막**, 카드뉴스 **이미지 속 글자**까지 읽어서
- 🇰🇷 **원래 언어 그대로 + 한국어 번역**으로 보여주고
- #️⃣ **캡션과 해시태그**까지 정리해 주는 프로그램이에요.

링크 **여러 개를 한 번에** 넣으면 차례대로 처리해요.
해외 릴스·카드뉴스 벤치마킹, 대본 분석, 자막 만들기에 쓰세요. **완전 무료**, API 키도 필요 없어요.

---

## 🚀 설치 & 실행

먼저 이 페이지 위쪽 초록색 **`<> Code`** 버튼 → **`Download ZIP`** 을 눌러 내려받으세요.

### 🪟 Windows

1. 받은 ZIP 파일을 **오른쪽 클릭 → 압축 풀기** (바탕화면처럼 찾기 쉬운 곳에)
2. 폴더 안의 **`run.bat` 더블클릭**
   - 처음 한 번은 필요한 프로그램을 **자동으로 설치**해요 (10~20분, 인터넷 속도에 따라 다름). Python이 없어도 알아서 깔아 줍니다.
   - 파란 경고창("Windows의 PC 보호")이 뜨면 **추가 정보 → 실행** 을 누르세요.
3. 설치가 끝나면 브라우저가 자동으로 열려요. 다음부터는 `run.bat` 만 더블클릭하면 바로 켜져요.

### 🍎 Mac (M1·M2·M3·M4 등 애플 실리콘)

1. 받은 ZIP 파일을 더블클릭해서 압축을 풀어요 (사파리는 자동으로 풀어 줘요).
2. 폴더 안의 **`run.command` 를 오른쪽 클릭(또는 control+클릭) → 열기 → 열기**
   - 처음에만 이렇게 열어야 해요. 그냥 더블클릭하면 "확인되지 않은 개발자" 경고로 막힐 수 있어요.
   - 그래도 안 열리면: **터미널** 앱을 열고 `bash ` (bash 뒤에 띄어쓰기 한 칸) 를 친 다음, `run.command` 파일을 터미널 창으로 끌어다 놓고 엔터.
   - 처음 한 번은 필요한 프로그램을 **자동으로 설치**해요 (10~20분).
   - Python 3.10 이상이 없으면 설치 페이지가 열려요. **macOS installer** 를 받아 설치한 뒤 다시 실행하세요. (Homebrew가 있으면 자동 설치)
3. 설치가 끝나면 브라우저가 자동으로 열려요. 다음부터는 `run.command` 더블클릭.

> 맥은 GPU 가속 없이 CPU로 처리해서 윈도우+NVIDIA 그래픽카드보다는 느려요 (릴스 1개에 1~3분 정도).
> 인텔 맥은 일부 AI 엔진이 지원되지 않아 설치가 안 될 수 있어요.

### 사용법

- 링크를 붙여넣고 **[추출하기]**. 여러 개는 **줄을 바꿔서** 붙여넣으면 돼요. 프로필에서 복사한 링크(`instagram.com/계정/p/...`)도 OK.
- 첫 추출 때는 음성·글자·화면 인식 AI 모델을 내려받느라 **몇 분 더** 걸려요 (한 번만).
- 다 쓰면 검은 창(맥은 터미널 창)을 닫으면 꺼집니다.

## ✨ 기능

| 기능 | 설명 |
|---|---|
| 🎬 영상 분석 리포트 (릴스) | **1) 제목 · 2) 스크립트 · 3) 타임라인과 화면 구성** 을 정리하고 텍스트로 한 번에 다운로드 (아래 설명) |
| 여러 링크 한 번에 | 대기열에 넣고 하나씩 처리, 끝난 것 모두 TXT 한 파일로 받기 |
| 릴스 · 카드뉴스 · 섞인 캐러셀 | 모든 장(영상/이미지)을 내려받아 장별로 보여줌, 전체 ZIP 저장 |
| 🗣️ 음성 → 텍스트 | 원문 / 한국어 나란히 보기, 복사, SRT 자막 저장 |
| 🔤 화면 속 자막 | 소리 없는 영상, 음악 + 자막 릴스도 OK. 시간대별로 정리, 계속 떠 있는 제목은 📌 고정 문구로 따로 표시, @아이디 워터마크는 자동 제거 |
| 🖼️ 이미지 속 글자 | 카드뉴스 각 장의 글자를 읽는 순서대로 추출 + 번역 |
| 타임라인 | 문장을 누르면 그 장면부터 재생, 재생 중인 문장 강조 |
| 캡션 & 해시태그 | 캡션 원문·번역, 해시태그 목록(외국어 태그는 뜻 표시), 멘션 |
| 기록 | 최근 추출한 결과 다시 보기 (`downloads` 폴더에 저장) |
| 🗑 정리 | 결과 하나씩 삭제 · 전체 삭제 · 사용 중인 저장 공간 표시 · 작업 목록 비우기 |

> 💡 글자 인식은 무료 AI(EasyOCR + PP-OCRv5)로 내 PC에서 처리해요. 꾸민 글씨나 아주 작은 글씨는
> 가끔 틀릴 수 있어요. Claude API 키를 넣으면 카드뉴스 글자를 Claude가 읽어서 거의 정확해져요.

## 🎬 영상 분석 리포트

릴스(영상 1개) 링크를 넣으면 결과 맨 위에 기획·벤치마킹용 리포트가 만들어져요. (카드뉴스·캐러셀은 제외)

| 항목 | 무료 모드 (기본) | Claude API 키를 넣으면 |
|---|---|---|
| 1) 제목 | 화면에 계속 떠 있는 제목 → 첫 화면 자막(후킹) → 캡션 첫 줄 순서로 자동 추정 | AI가 영상을 보고 주제 한 줄 + 요약 + 핵심 포인트 정리 |
| 2) 스크립트 | 음성 받아쓰기(없으면 화면 자막)를 시간순 정리 + 한국어 | 받아쓰기 오류를 문맥에 맞게 고친 자연스러운 나레이션 |
| 3) 타임라인과 화면 구성 | 컷 전환 기준으로 장면을 나누고, 장면마다 대표 화면 + **화면 설명**(내 PC의 이미지 AI가 작성) + 자막, 맨 위에 **전체 화면 구성 요약** | 화면 설명을 Claude가 더 자연스럽게 작성 |

- **⬇ 제목·스크립트·타임라인 TXT** 버튼으로 세 항목을 텍스트 파일 하나로 받을 수 있고, **전체 복사**로 노션·문서에 바로 붙여넣을 수도 있어요.
- 무료 모드의 화면 설명은 이미지 AI(Microsoft Florence-2, 내 PC에서 실행)가 장면을 보고 영어로 쓴 걸 한국어로 번역한 거라 표현이 조금 어색할 수 있어요.
- 번역은 Google 번역을 쓰고, Google이 잠깐 막혀도 **내 PC 번역(M2M100)** 이 대신 해서 화면 설명은 항상 한국어로 나와요.
- 예전에 추출한 릴스도 결과 화면의 **영상 분석 만들기 / 화면 설명 추가하기 / 다시 분석** 버튼으로 나중에 분석할 수 있어요.
- AI 분석 비용은 릴스 1개에 대략 100~300원 정도예요 (영상 길이·장면 수에 따라 다름, Claude Opus 5.5 기준 추정).

## 💻 PC 사양

- **Windows 10 / 11**, **macOS (애플 실리콘 M1 이상)**
- **NVIDIA 그래픽카드가 있으면** 자동으로 GPU를 써서 빠르고 정확해요 (가장 정확한 `large-v3` 모델).
- 그래픽카드가 없어도 돌아가요. CPU용 `small` 모델로 처리하고, 화면 자막 읽기는 좀 느려져요 (1분 영상에 1~2분).
- 디스크 여유 공간: 약 14GB (그래픽카드 없으면 약 6GB)

## ❓ 자주 묻는 문제

**"login required" / 로그인이 필요하다는 오류가 나요**
비공개 계정이거나, 짧은 시간에 너무 많이 요청해서 인스타가 잠깐 막은 경우예요. 몇 분 뒤 다시 해 보고, 그래도 안 되면:
1. 크롬 확장 프로그램 **"Get cookies.txt LOCALLY"** 설치
2. 인스타그램에 로그인한 상태에서 확장 프로그램으로 쿠키 내보내기
3. 받은 파일 이름을 `cookies.txt` 로 바꿔서 이 폴더(`run.bat` 있는 곳)에 넣기

> ⚠️ `cookies.txt` 는 내 인스타 로그인 정보예요. **절대 다른 사람에게 주지 마세요.**

**맥에서 `CERTIFICATE_VERIFY_FAILED` 오류가 나요**
python.org에서 설치한 Python이 인증서를 못 찾아서 생기는 문제예요. 최신 버전에서는 자동으로 해결되니 **ZIP을 다시 받아 덮어쓰고** `run.command` 를 실행하세요.
그래도 나오면 Finder → 응용 프로그램 → `Python 3.x` 폴더의 **`Install Certificates.command`** 를 더블클릭한 뒤 다시 실행하세요.

**"추출된 텍스트가 없어요"라고 나와요**
말소리도, 화면 속 글자도 없는 영상·사진이에요.

**번역이 좀 딱딱해요**
기본은 무료 Google 번역이에요. Claude API 키가 있으면 말투까지 살린 자연스러운 번역이 돼요.
`.env.example` 파일을 복사해서 이름을 `.env` 로 바꾸고, `ANTHROPIC_API_KEY=` 뒤에 키를 붙여 넣으세요.

**갑자기 다운로드가 안 돼요**
인스타그램이 사이트 구조를 바꾼 경우예요. `run.bat`(맥은 `run.command`)을 다시 실행하면 다운로더가 자동으로 최신 버전으로 업데이트돼요.

**완전히 지우고 다시 설치하고 싶어요**
폴더 안의 `.venv` 폴더를 지우고 `run.bat`(맥은 `run.command`)을 다시 실행하세요. (맥에서 `.venv` 가 안 보이면 Finder에서 command+shift+. 을 누르세요)
(폴더 경로가 아주 길면 실행 환경이 `%LOCALAPPDATA%\InstaText` 안에 만들어져요. 그때는 그 폴더를 지우세요.)

**프로그램을 지우고 싶어요**
이 폴더를 통째로 지우면 돼요. AI 모델 파일은 따로 저장돼 있어서, 공간을 완전히 비우려면
`%USERPROFILE%\.cache\huggingface`, `%USERPROFILE%\.EasyOCR`, `%LOCALAPPDATA%\InstaText` 폴더도 지우세요.

## ⚙️ 고급 설정 (`.env`)

`.env.example` 을 `.env` 로 복사해서 수정하세요. 전부 선택 사항이에요.

| 설정 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | 넣으면 Claude로 영상 분석 + 번역 + 카드뉴스 글자 읽기 (없으면 무료 모드: Google 번역 + 무료 OCR) |
| `ANTHROPIC_MODEL` | 사용할 Claude 모델 (기본 `claude-opus-5-5`) |
| `SCREEN_OCR` | `0` 으로 하면 영상 화면 속 자막 읽기를 끔 (더 빨라짐) |
| `WHISPER_MODEL` | GPU에서 쓸 음성 인식 모델 (기본 `large-v3`) |
| `WHISPER_MODEL_CPU` | CPU에서 쓸 모델 (기본 `small`, 더 정확하게 하려면 `medium`) |
| `WHISPER_DEVICE` | `auto`(기본) / `cuda` / `cpu` |
| `COOKIES_FROM_BROWSER` | `firefox` 등, cookies.txt 대신 브라우저에서 쿠키 읽기 |
| `PORT` | 사이트 주소 포트 (기본 8000) |

- Google 번역 / Claude API — 번역
- FastAPI — 웹 화면
